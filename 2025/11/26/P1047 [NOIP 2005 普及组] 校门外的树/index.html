P1047 [NOIP 2005 普及组] 校门外的树

题目描述

某校大门外长度为 l 的马路上有一排树，每两棵相邻的树之间的间隔都是 1 米。我们可以把马路看成一个数轴，马路的一端在数轴 0 的位置，另一端在 l 的位置；数轴上的每个整数点，即 0,1,2,…,l，都种有一棵树。

总共有 ( l + 1 ) 棵树，因为从 0 到 l 共有 ( l + 1 ) 个整数点。

由于马路上有一些区域要用来建地铁。这些区域用它们在数轴上的起始点和终止点表示。已知任一区域的起始点和终止点的坐标都是整数，区域之间可能有重合的部分。现在要把这些区域中的树（包括区域端点处的两棵树）移走。你的任务是计算将这些树都移走后，马路上还有多少棵树。

输入格式

第一行有两个整数，分别表示马路的长度 l 和区域的数目 m。

接下来 m 行，每行两个整数 u,v，表示一个区域的起始点和终止点的坐标。

输出格式

输出一行一个整数，表示将这些树都移走后，马路上剩余的树木数量。

说明/提示

  • 数据范围：

    • 对于 20% 的数据，保证区域之间没有重合的部分。
    • 对于 100% 的数据，保证 1 ≤ l ≤ 10000，1 ≤ m ≤ 100，0 ≤ u ≤ v ≤ l。

  • 题目来源：NOIP 2005 普及组第二题

解题思路

这是一个典型的区间覆盖问题，我们需要计算被各个区域覆盖后，剩余未被覆盖的树的数量。以下是问题的可视化表示：

主要有以下几种解题思路：

方法一：模拟法（数组标记）

  1. 创建一个长度为 l+1 的数组，表示数轴上的每个点是否有树
  2. 初始时，所有位置都有树（标记为 True 或 1）
  3. 对于每个区域 [u, v]，将区间内的所有点标记为无树（标记为 False 或 0）
  4. 最后统计数组中仍然为有树的点的数量

方法二：集合去重法

  1. 创建一个集合，用于存储需要移走的树的位置
  2. 对于每个区域 [u, v]，将区间内的所有位置添加到集合中
  3. 由于集合的特性，自动去除重复的位置
  4. 计算剩余的树的数量 = 总树数 - 集合的大小

方法三：区间合并优化

  1. 先将所有区域按照起始点排序
  2. 合并重叠或相邻的区间
  3. 计算所有合并后区间的总长度
  4. 用总树数减去被覆盖的树数得到剩余树数

代码解析

方法一：模拟法（数组标记）

  • 思路：使用布尔数组直接模拟每棵树的状态
  • 步骤：
    1. 输入马路长度 l 和区域数量 m
    2. 创建长度为 l+1 的布尔数组 trees，初始值都为 True（表示有树）
    3. 对于每个区域 [u, v]，将区间内的所有位置标记为 False（表示无树）
    4. 使用 sum() 函数统计数组中 True 的数量，即为剩余的树的数量
  • 优点：思路简单直观，实现容易
  • 缺点：当 l 很大时，数组会占用较大内存；当 m 和区间较大时，时间复杂度较高

方法二：集合去重法

  • 思路：使用集合存储需要移走的树的位置，自动去重
  • 步骤：
    1. 输入马路长度 l 和区域数量 m
    2. 创建空集合 to_remove
    3. 对于每个区域 [u, v]，将区间内的所有位置添加到集合中
    4. 计算剩余的树的数量 = 总树数 (l+1) - 集合的大小（即需要移走的树的数量）
  • 数学表示：对于区间 [u, v]，该区间内有 ( v - u + 1 ) 棵树需要移走。通过集合的特性，自动去除了重叠区间中的重复计数。
  • 优点：自动处理区域重叠的情况，不需要额外的去重逻辑
  • 缺点：当区间很大时，循环添加元素的操作仍然效率不高

方法三：区间合并法（优化）

  • 思路：先合并重叠或相邻的区间，再计算被覆盖的总长度
  • 步骤：
    1. 输入马路长度 l 和区域数量 m
    2. 存储所有区域到列表中
    3. 按照起始点对区域进行排序
    4. 合并重叠或相邻的区间：
      • 遍历排序后的区域列表
      • 如果当前区间与上一个合并后的区间不重叠，则添加为新的合并区间
      • 否则，合并两个区间，更新结束点为较大的值
    5. 计算所有合并后区间的总长度
    6. 计算剩余的树的数量 = 总树数 (l+1) - 被覆盖的总长度
  • 数学表示：
    • 区间合并条件：对于两个区间 [a, b] 和 [c, d]，当 c ≤ b+1 时，两个区间需要合并
    • 合并后的区间为 [min(a, c), max(b, d)]
    • 合并后区间的总覆盖长度为：( \sum_{i=1}^{k} (v_i - u_i + 1) )，其中 k 是合并后的区间数量，(u_i, v_i) 是第 i 个合并后的区间
    • 最终剩余树数：( (l + 1) - \sum_{i=1}^{k} (v_i - u_i + 1) )
  • 优点：当有大量重叠区间时，效率更高；不依赖于 l 的大小，节省内存
  • 缺点：实现稍微复杂一些

复杂度分析

方法一：模拟法（数组标记）

  • 时间复杂度：( O(m \times \text{max_length}) )，其中 max_length 是区间的最大长度
    • 读取输入：( O(m) )
    • 标记区间：( O(m \times \text{max_length}) )
    • 统计剩余树：( O(l) )
  • 空间复杂度：( O(l) )
    • 需要一个长度为 l+1 的数组

方法二：集合去重法

  • 时间复杂度：( O(m \times \text{max_length}) )
    • 读取输入：( O(m) )
    • 添加元素到集合：( O(m \times \text{max_length}) )
    • 计算结果：( O(1) )
  • 空间复杂度：( O(l) )
    • 在最坏情况下，需要存储所有点

方法三：区间合并法

  • 时间复杂度：( O(m \times \log m) )
    • 读取输入：( O(m) )
    • 排序区间：( O(m \times \log m) )
    • 合并区间：( O(m) )
    • 计算覆盖长度：( O(m) )
  • 空间复杂度：( O(m) )
    • 需要存储所有区间

优化建议

对于本题的数据范围（l ≤ 10000，m ≤ 100），三种方法都能轻松通过。但如果数据范围更大，比如 l 到 10^9 或 m 到 10^5，那么方法三（区间合并法）会是最优的选择。

在实际编程竞赛中，我们通常会根据数据范围选择合适的算法。对于本题，由于数据范围较小，最简单直观的方法一或方法二可能是首选，因为它们实现简单，不易出错。

输出计算过程
