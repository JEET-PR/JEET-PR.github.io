Python简介与环境搭建

什么是Python？

Python是一种高级编程语言，由Guido van Rossum于1989年创建。它具有以下特点：

  • 简洁易读：语法清晰，接近自然语言
  • 跨平台：可在Windows、macOS、Linux上运行
  • 丰富的库：拥有庞大的标准库和第三方库
  • 多范式：支持面向对象、函数式、过程式编程

1. 列表 (list)

创建列表示例：

列表切片示例：

列表推导式示例：

讲解：

  • 列表特点：有序、可变、允许重复元素
  • 列表创建：用方括号[]包围，元素用逗号分隔
  • 列表操作：
    • append()：在末尾添加元素
    • insert(index, element)：在指定位置插入元素
    • remove(element)：删除指定元素（首次出现的）
    • pop()：弹出并返回最后一个元素
  • 切片操作：list[start:end:step]
    • start：起始索引（包含），省略则从0开始
    • end：结束索引（不包含），省略则到末尾
    • step：步长，省略则为1
  • 列表推导式：简洁的列表生成方式，语法为[表达式 for 变量 in 可迭代对象 if 条件]

列表切片数学表示

对于列表 $L = [l_0, l_1, l_2, ..., l_{n-1}]$，切片操作 $L[start:end:step]$ 可以表示为：

$L[start:end:step] = \{l_i | start \leq i < end, i \equiv start \pmod{step}\}$

时间复杂度分析：

  • 访问元素：$O(1)$
  • 插入/删除头部：$O(n)$
  • 插入/删除尾部：$O(1)$
  • 切片操作：$O(k)$，其中k是切片长度

函数数学表示

函数可以表示为映射关系：$f: X \rightarrow Y$

复合函数：$(f \circ g)(x) = f(g(x))$

递归函数：$f(n) = \begin{cases} base\_case & \text{if } n = n_0 \\ f(n-1) + \text{operation} & \text{if } n > n_0 \end{cases}$

文件操作数学模型：

  • 文件大小：$S = \sum_{i=1}^{n} |l_i|$，其中$l_i$表示第$i$行
  • 读取效率：$E_{\text{read}} = \frac{\text{数据量}}{\text{时间}}$

  • 文件指针位置：$P = P_0 + \Delta P$

文件路径操作

文件路径数学公式：

  • 绝对路径：$\text{path}_{\text{abs}} = \text{root} + \text{relative\_path}$
  • 路径连接：$\text{path}_{\text{joined}} = \text{path}_1 \oplus \text{path}_2$
  • 目录遍历：$\text{files} = \{f | f \in \text{directory} \land \text{is\_file}(f)\}$
  • 路径规范化：$\text{path}_{\text{norm}} = \text{normalize}(\text{path}_{\text{raw}})$

基本异常处理

异常处理数学模型：

  • 异常概率：$P(\text{exception}) = \frac{\text{异常次数}}{\text{总执行次数}}$
  • 错误率：$E = 1 - \frac{\text{成功次数}}{\text{总尝试次数}}$
  • 异常处理效率：$\eta = \frac{\text{正常执行时间}}{\text{包含异常处理的执行时间}}$
  • 异常传播深度：$D = \sum_{i=1}^{n} \text{level}_i$

    • else：没有异常时执行（可选）
    • finally：无论是否有异常都执行（可选）
  • 常见异常类型：
    • ValueError：值错误，如字符串转数字失败
    • ZeroDivisionError：除零错误
    • Exception：所有异常的基类
  • 异常捕获顺序：从具体到一般，先捕获子类异常
  • 异常对象：as e获取异常对象，包含错误信息
  • 多重异常：可以用元组同时捕获多种异常类型
  • 异常处理原则：只捕获能处理的异常，避免掩盖错误

异常匹配算法：

  • 异常类型匹配：$T_{\text{match}} = \{t | t \in \text{except\_types} \land t \subseteq \text{exception\_type}\}$
  • 最佳匹配选择：$T_{\text{best}} = \arg\min_{t \in T_{\text{match}}} \text{distance}(t, \text{exception\_type})$
  • 异常处理优先级：$\text{Priority}(t_1) > \text{Priority}(t_2) \iff t_1 \text{在代码中位置更靠前}$
