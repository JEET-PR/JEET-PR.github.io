P1002 [NOIP 2002 普及组] 过河卒 题解

题目描述

棋盘上的 A 点有一个过河卒，需要走到目标 B 点。卒行走的规则：可以向下、或者向右。同时在棋盘上 C 点有一个对方的马，该马所在的点和所有跳跃一步可达的点称为对方马的控制点。因此称之为"马拦过河卒"。

棋盘用坐标表示，A 点 (0, 0)、B 点 (n, m)，同样马的位置坐标是需要给出的。

现在要求你计算出卒从 A 点能够到达 B 点的路径的条数，假设马的位置是固定不动的，并不是卒走一步马走一步。

输入格式
一行四个正整数，分别表示 B 点坐标和马的坐标。

输出格式
一个整数，表示所有的路径条数。

输入输出样例
输入 #1

输出 #1

问题分析

这道题是一个典型的动态规划问题，主要考察以下几个方面：

  1. 状态定义：如何定义状态来表示到达某个点的路径数
  2. 状态转移方程：如何从已有的状态计算新的状态
  3. 边界条件：初始位置和特殊位置（马的控制点）的处理
  4. 棋盘范围：确保不会越界访问

首先，我们需要明确几点：

  • 卒只能向右或向下移动
  • 马的位置和其八个控制点卒不能经过
  • 我们需要计算从(0,0)到(n,m)的所有有效路径数目

对于这样的网格路径计数问题，动态规划是最适合的解法。因为到达某个点的路径数只取决于它上方和左方的点的路径数之和（因为卒只能向右或向下移动）。

数学公式表示

动态规划状态定义

我们定义 dp[i][j] 表示从起点 (0,0) 到达位置 (i,j) 的路径数目。

状态转移方程

由于卒只能向右或向下移动，所以到达 (i,j) 的路径只能来自于 (i-1,j)（上方）或 (i,j-1)（左方）。因此状态转移方程为：

$$dp[i][j] = dp[i-1][j] + dp[i][j-1] $$

边界条件的数学表示

边界条件可以用数学表达式表示为：

  1. 起点：$dp[0][0] = 1$，表示起点本身就是一个路径

  2. 第一行（$i = 0, j > 0$）：

    $$dp[0][j] = \begin{cases} dp[0][j-1] & \text{如果位置}(0,j)\text{不是马的控制点}\\ 0 & \text{如果位置}(0,j)\text{是马的控制点} \end{cases}$$

  3. 第一列（$j = 0, i > 0$）：

    $$dp[i][0] = \begin{cases} dp[i-1][0] & \text{如果位置}(i,0)\text{不是马的控制点}\\ 0 & \text{如果位置}(i,0)\text{是马的控制点} \end{cases}$$

马控制点的数学处理

对于马的位置 $(hx, hy)$ 及其八个控制点，我们可以用以下方式表示：

$$\text{chessboard}[x][y] = \begin{cases} 1 & \text{如果}(x,y)\text{是马的位置或控制点}\\ 0 & \text{否则} \end{cases}$$

马的八个控制点可以用偏移量来表示：

$$\text{控制点} = \{(hx+dx, hy+dy) | (dx, dy) \in \{(-2,-1), (-2,1), (-1,-2), (-1,2), (1,-2), (1,2), (2,-1), (2,1)\}\} $$

当位置 $(i,j)$ 是马的控制点时，路径数为 0：

$$dp[i][j] = 0 \quad \text{当 chessboard}[i][j] = 1 $$

完整的状态转移方程

综合以上条件，完整的状态转移方程为：

$$dp[i][j] = \begin{cases} 0 & \text{如果}(i,j)\text{是马的控制点}\\ 1 & \text{如果}(i,j) = (0,0)\\ dp[0][j-1] & \text{如果}i=0\text{且}j>0\text{且不是控制点}\\ dp[i-1][0] & \text{如果}j=0\text{且}i>0\text{且不是控制点}\\ dp[i-1][j] + dp[i][j-1] & \text{否则} \end{cases}$$

无阻碍情况下的路径数

在没有马阻碍的情况下，从 $(0,0)$ 到 $(n,m)$ 的路径数可以用组合数学计算：

$$\text{路径数} = \binom{n+m}{n} = \frac{(n+m)!}{n! \cdot m!} $$

这表示在总共 $(n+m)$ 步中选择 $n$ 步向下（或 $m$ 步向右）的组合数。

整体算法流程图

    FirstRow -- "否" --> FirstCol{"是否为第一列？"}
    FirstCol -- "是" --> SetTop["dp[i][j]=dp[i-1][j]"]
    FirstCol -- "否" --> SetSum["dp[i][j]=dp[i-1][j]+dp[i][j-1]"]
    SetLeft --> NextCol
    SetTop --> NextCol
    SetSum --> NextCol
    NextCol --> LoopCol
    LoopCol --> NextRow["行遍历结束"]
    NextRow --> LoopRow
    LoopRow --> Output["输出 dp[n][m]"]
    Output --> FIN["结束"]

解决这个问题的算法流程如下：

  1. 读取输入：n, m, hx, hy（终点坐标和马的坐标）
  2. 创建一个标记数组，标记马的控制点
  3. 创建动态规划数组 dp
  4. 初始化边界条件
  5. 按行或按列填充动态规划数组
  6. 返回 dp[n][m] 作为结果

解法二：优化空间的动态规划解法

由于每次计算 dp[i][j] 只需要用到 dp[i-1][j] 和 dp[i][j-1]，我们可以使用一维数组来优化空间复杂度：

复杂度分析

时间复杂度

  • 时间复杂度：$O(n \times m)$
  • 我们需要填充一个 $(n+1) \times (m+1)$ 的动态规划数组，每个位置的计算都是常数时间的操作。
  • 数学表示：$T(n,m) = O(n \times m)$

空间复杂度

  • 解法一的空间复杂度：$O(n \times m)$

    • 需要两个二维数组：一个用于标记马的控制点，一个用于动态规划
    • 数学表示：$S(n,m) = O(n \times m)$

  • 解法二的空间复杂度：$O(n \times m + m) = O(n \times m)$

    • 需要一个二维数组标记马的控制点
    • 动态规划使用一维数组，空间为 $O(m)$
    • 数学表示：$S(n,m) = O(n \times m)$

代码解析

解法一详细分析

  1. 输入处理：

    读取终点坐标 (n, m) 和马的坐标 (hx, hy)。

  2. 标记马的控制点：

    创建一个二维数组 chessboard，标记马的位置和其八个控制点。

  3. 初始化DP数组：

    创建动态规划数组 dp，并将起点 dp[0][0] 初始化为 1。

  4. 填充DP数组：

    按行遍历棋盘，对于每个位置：

    • 如果是马的控制点，路径数为 0
    • 如果是第一行，则只能从左边来
    • 如果是第一列，则只能从上边来
    • 否则，路径数等于上边和左边的路径数之和

  5. 输出结果：

    输出到达终点 (n, m) 的路径数。

解法二详细分析

解法二使用一维数组来优化空间复杂度：

  1. 输入处理和标记马的控制点：与解法一相同

  2. 创建一维DP数组：

    创建一个长度为 m+1 的一维数组，用于存储当前行的动态规划状态。

  3. 按行填充DP数组：

    • 一维数组 dp[j] 在每一行遍历时存储的是当前行第 j 列的路径数
    • 当处理到第 i 行时，dp[j] 的旧值代表的是上一行（i-1）第 j 列的路径数
    • dp[j-1] 代表的是当前行前一列（j-1）的路径数
    • 这样，我们就可以在一维空间中完成状态转移

这种优化的核心思想是：由于每次计算只依赖于上方和左方的值，我们可以重复使用一个一维数组，通过覆盖旧值来节省空间。

总结

P1002 过河卒是一道经典的动态规划问题，通过这道题我们可以学习到：

  1. 动态规划的基本思想：通过将问题分解为子问题，记录子问题的解来避免重复计算
  2. 状态定义与转移：如何定义状态并建立状态转移方程
  3. 边界条件的处理：如何处理特殊情况如起点、边界行/列
  4. 障碍物的处理：如何在动态规划中考虑障碍物的影响
  5. 空间优化：如何通过一维数组优化二维动态规划的空间复杂度

这道题虽然看似简单，但其中包含了动态规划的核心思想，是学习动态规划的很好的入门题目。通过解决这个问题，我们可以为后续学习更复杂的动态规划问题打下坚实的基础。

在实际编程中，我们还需要注意以下几点：

  • 数组下标越界问题：确保访问的坐标在合法范围内
  • 初始化：正确初始化起点和边界条件
  • 特殊情况处理：如障碍物在起点或终点的情况

通过这道题，我们可以体会到动态规划在解决路径计数问题中的强大作用。
