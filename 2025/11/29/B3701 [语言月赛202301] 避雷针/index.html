B3701 [语言月赛202301] 避雷针

题目描述

n 个避雷针从左至右排成一排，我们将它们从左至右依次标号为 1∼n。

现在有 ( m ) 道雷依次劈下。你得知了一串序列 ( a_1, a_2, \ldots, a_m )。对于第 ( i ) 道雷，其劈中了 ( a_i{-}2 )（如果存在）、( a_i{-}1 )（如果存在）、( a_i )、( a_i{+}1 )（如果存在）、( a_i{+}2 )（如果存在）号避雷针。

在 ( m ) 道雷劈完后，你想要知道，被劈过至少一次的避雷针有几个。

输入格式

输入共两行。

第一行为两个整数 ( n, m )，代表避雷针数量和雷的数量。

第二行为 ( m ) 个整数 ( a_1, a_2, \ldots, a_m )，代表题面中的序列。

输出格式

输出共一行。

输出一行一个整数，被劈过至少一次的避雷针的数量。

问题分析

这个问题的核心是：

  1. 我们需要跟踪每个避雷针是否被劈中过
  2. 对于每道雷击中的位置 ( a_i )，它会影响 ( a_i-2 ) 到 ( a_i+2 ) 的范围（如果存在）
  3. 我们需要统计最终被劈中至少一次的避雷针数量

问题的关键在于如何高效地标记被击中的避雷针，并考虑边界情况（比如 ( a_i-2 ) 小于1或 ( a_i+2 ) 大于 ( n ) 的情况）。

代码解析

解法一详细分析

  1. 输入处理：

    • 读取避雷针数量 ( n ) 和雷的数量 ( m )
    • 读取 ( m ) 个雷击中的位置序列

  2. 标记数组初始化：

    • 创建一个长度为 ( n+1 ) 的布尔数组 hit，索引0不使用，索引1到n分别对应1到n号避雷针
    • 初始时所有值设为False，表示都未被击中

  3. 处理每道雷：

    • 对于每个击中位置 ( a )，计算其影响范围的起始和结束位置
    • 使用 max(1, a-2) 确保起始位置不小于1
    • 使用 min(n, a+2) 确保结束位置不大于n
    • 将范围内的所有避雷针标记为True

  4. 结果统计：

    • 统计标记数组中True的数量，即从索引1到n的和
    • 输出统计结果

解法二优化说明

解法二使用集合（set）来优化代码：

  1. 使用集合的优势：

    • 集合自动去重，不需要担心重复标记同一个避雷针
    • 使用 update() 方法可以批量添加元素，代码更简洁
    • 集合的 len() 方法直接给出元素个数，不需要额外统计

  2. 时间复杂度分析：

    • 添加元素到集合的操作平均时间复杂度为O(1)
    • 对于每道雷，最多添加5个元素，总共最多添加5m个元素
    • 总体时间复杂度为O(m)

解法三特殊情况

解法三使用位运算，仅适用于 ( n ) 较小的情况（Python中整数大小不受限制，所以实际上可以处理较大的n）：

  1. 位掩码的概念：

    • 使用整数的二进制位来表示状态
    • 第i位为1表示第i个避雷针被击中

  2. 位运算操作：

    • 使用按位或操作 | 来设置位
    • 使用左移操作 < 来定位到对应的位

  3. 适用场景：

    • 当n不是特别大时（比如n < 1000），这种方法非常高效
    • 但对于本题的数据规模（n可达1e5），这种方法会消耗过多内存，不推荐使用

算法分析

时间复杂度

  • 解法一：时间复杂度为O(m * 5) = O(m)，因为每道雷最多影响5个避雷针
  • 解法二：时间复杂度为O(m * 5) = O(m)，集合的更新操作平均时间复杂度为O(1)
  • 解法三：时间复杂度同样为O(m * 5) = O(m)

由于m的值可以达到1e5，所以上述三种解法的时间复杂度在实际应用中是可行的。

空间复杂度

  • 解法一：空间复杂度为O(n)，需要一个长度为n+1的数组
  • 解法二：空间复杂度为O(k)，其中k是被击中的避雷针数量，最坏情况下k=n
  • 解法三：空间复杂度为O(1)，只使用一个整数变量，但实际上Python整数内部存储会随位数增加而消耗更多内存

对于本题，解法二在大多数情况下空间效率最高，因为它只存储实际被击中的避雷针编号。

边界情况讨论

1. 当a_i-2 < 1时

例如，当a_i=1时，左侧边界被限制为1，只考虑1,2,3这三个位置。

2. 当a_i+2 > n时

例如，当a_i=n时，右侧边界被限制为n，只考虑n-2,n-1,n这三个位置。

3. 当m=0时

这种情况不会有雷击中任何避雷针，输出0。虽然题目中可能不会出现这种情况，但在代码中应该能够正确处理。

4. 当多个雷击中相同或重叠的区域

这时候需要确保每个避雷针只被计数一次，无论被击中多少次。解法二的集合方法天然地处理了这种情况。

如果我们不仅需要知道被击中的数量，还需要知道每个避雷针被击中的次数，应该如何修改？

总结

本题是一个典型的范围标记和统计问题，主要考察以下几点：

  1. 边界条件处理：确保在计算影响范围时不会越界
  2. 去重统计：确保每个被击中的避雷针只计数一次
  3. 数据结构选择：根据问题特点选择合适的数据结构（数组、集合或位掩码）

在Python中，使用集合（set）是解决此类问题的高效方法，因为集合自动处理了去重问题，并且提供了简洁的API。对于大规模数据，我们需要考虑时间和空间复杂度，选择最优的解决方案。

解决这类问题的关键思路是：

  1. 明确问题的影响范围和边界条件
  2. 选择合适的数据结构来高效地标记和统计
  3. 注意处理重复情况，确保结果正确
